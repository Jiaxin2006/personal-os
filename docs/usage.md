# Personal OS 本地 MVP

这是可自行构建、无需账户或订阅的 macOS 原生开发版。界面为 SwiftUI，业务层复用 Python 标准库和 SQLite；构建前运行 `tools/fetch_python.py` 时，应用自带 Python 运行时（Apple 芯片），不需要本机安装；否则使用本机 Python 3.9+。尚未完成 Mac App Store 签名与沙盒验证。

## 使用

1. 打开 `Personal OS.app`。在「设置 → 界面语言」选择「跟随系统」「简体中文」或「English」，退出并重新打开后生效。
2. 在「设置」调整时间类别、是否计入工作、达标标准、约束强度和周期任务。每个类别另有一个「状态栏名称」（一个英文单词，如 Reading），SketchyBar 只显示这个英文名。
3. 在「时间」或菜单栏开始、暂停、继续、结束或切换活动。切换活动会先保存上一段，再开始新类别。
4. 在「复盘」查看当前待办、全部历史和周复盘；草稿与完成记录保存在本地。
5. 用「导出备份」保存完整 JSON 备份，用「导入备份」校验并恢复到新工作区。原数据目录保留。保存框里确认「替换」后，新备份完整写好才替换旧文件。

## 每日彩蛋

每天第一次打开主窗口时，先显示一幅名画和一句诗词，点「开始今天」、按回车或 Esc 进入。总览页顶部也有当天的画与诗，点一下可再看完整画作。在「设置 → 每日彩蛋」可关闭开屏。

- 诗词：98 句唐宋为主的名句（`assets/poems.json`），按季节优先选应季的；春节、元宵、端午、七夕、中秋、重阳、除夕按农历换成节日诗句。
- 发布时内置 30 幅大都会艺术博物馆的开放获取画作（CC0），名单在 `assets/paintings.json`。应用按日期轮播，大约每 30 天循环一次。图片随应用存放在 `Contents/Resources/Daily/`，可以离线观看。
- 构建时会下载缺少的内置画作。图片缓存保存在 Git 忽略的 `assets/paintings/`，用 `python3 tools/fetch_paintings.py --refresh` 可重新下载。

### 扩充本机画库

在大都会馆藏页面找到想加入的画作，将网址末尾的馆藏编号传给下载工具。工具只收录馆藏 API 标为公有领域且提供图片的作品，作品名称采用馆方提供的原文。

```sh
python3 tools/fetch_paintings.py --local 435877 436534
python3 tools/build_macos.py --local-gallery --output "$HOME/Desktop/Personal OS.app"
```

扩展画作保存在 `~/Library/Application Support/Personal OS/Local Paintings/`，与内置作品合并参与每日轮播。以后加画只需再运行第一条命令并重新打开应用，已下载的作品会跳过。

本机版优先展示还没出现过的作品。剩余 5 幅或更少时，应用在后台从大都会馆藏搜索并下载最多 8 幅公有领域画作，每天最多尝试一次。下载完成后从后续日期加入轮播。离线时继续使用已下载的作品，轮完后可以再次观看。

科研时长与有效科研天数分别判断。默认科研频率为每周至少4天，各日累计至少1.5小时；阅读为至少3天，各日累计至少30分钟。每个自然日可以分多段累计，超额投入不会多算一天。

Dashboard 正式统计只计已保存记录，正在计时的部分单独展示。计时引擎版本 2 起，每条记录保存当天的开始和结束时刻（含中间暂停），「时间」页显示为「09:30–11:00」；更早的记录只有日期和秒数，显示为「只有当天总时长」，不虚构起止时刻。点击一条记录可以删除；计时记录删除后会在账本的 `deleted_sessions` 表留一份副本，旧日志文件里的记录不能在应用里删除。每日分布图上悬停某一天，可看到当天各类别的具体时长。菜单栏计时图标默认关闭，可在「设置 → 菜单栏」打开。

## 数据位置与保护

- 新配置、手工补记、目标版本、周期任务和复盘默认放在 `~/Library/Application Support/Personal OS/personal_os.sqlite3`。
- 已有计时与旧日志继续使用 `~/.config/sketchybar/data`，不复制入新库再重复累计。
- 应用和 SketchyBar 共享同一计时状态与 SQLite 事务；不会同时启动第二套独立计时账本。
- 已部署的计时适配支持动态类别、归档类别和快速重启恢复；原菜单栏类别选择仍是修正整次计时，新应用「切换活动」是从切换时刻分段。
- 模板和实例分开保存。显示日期与截止日期独立，已生成的历史实例保留原规则；月末7天窗口包含截止日当天。
- 目标修改当前立即生效，配置旧版本保留；已完成周复盘使用固定统计与目标快照。未来日期生效尚未实现。
- 同一系统启动期间若超过60秒没有可信心跳，原生计时服务恢复时保守暂停在最近一次心跳；未知停机间隔不默认为工作。
- 导入会保留原文件并切换到新工作区，恢复配置、补记、周期任务和复盘。若本机已有计时记录（SketchyBar 或应用自己的计时目录），计时继续写入这份记录，备份中的计时历史只存放在恢复目录的 `legacy/` 备查，不合并、不重复累计；本机没有计时记录时（例如换了一台 Mac），才接着使用备份中的计时历史，其中运行中的计时暂停在备份里最后一次可信时刻。
- 应用只在计时运行时每 10 秒、空闲时每 20 秒向本地组件同步一次，切回应用时立即刷新；界面上的计时每秒在本地走动。只读刷新不写数据库。

真实计时记录不写入仓库。

## 构建与验证

```sh
python3 -m unittest discover -s tests -v
python3 tools/fetch_python.py
python3 tools/build_macos.py
```

构建结果为 `dist/Personal OS.app`。在 Apple 芯片 Mac 上运行以下命令即可生成用于 GitHub Release 的 ZIP。

```sh
ditto -c -k --sequesterRsrc --keepParent "dist/Personal OS.app" "dist/Personal-OS-macos-arm64.zip"
```

构建使用本机 Swift 编译器和 macOS SDK，生成当前机器架构的 ad-hoc 签名应用。断网时可以用 `--without-paintings` 构建只带诗词的开发版。图标使用 `assets/icons/` 中已经准备好的 PNG 和多尺寸 ICNS，并在启动时明确设置 Dock 图标。更新图标后可用 `python3 tools/prepare_app_icon.py` 重新打包资源（此步骤需要 Pillow，应用运行不需要）。macOS 最低版本 13，发布版兼容性仍需其他机器验证。

升级共享计时插件前先执行一致备份：

```sh
backup=$(python3 tools/backup_history.py)
python3 ../sketchybar/tools/install_mvp_timer.py --backup "$backup"
```

备份默认存在 `~/Library/Application Support/Personal OS/Timer Backups/`，按日期时间命名，不放桌面；也可以在第一行末尾写上想要的位置。第一行在本仓库执行；安装器属于同级 `sketchybar` 仓库，部署的是那里的计时插件和菜单配置。安装器验证备份后只替换这两个文件，不覆盖个人历史数据库。不要用删除数据库的方法重置计时。本仓库的 `plugins/timer.py` 是同一引擎的副本，见根目录 README。
