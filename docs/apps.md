# 是否已有类似应用

调研日期：2026-11-05。依据官网、帮助文档及 App Store 产品页；本轮未安装试用，也未导入个人数据。这里的“未验证”表示公开资料不能确认，不能据此宣称产品没有该功能。

结论：**有，时间预算、自动计时、习惯频率、周期任务分别已有成熟或直接相近的产品。** 每周时间预算本身不是空白市场。本轮没有验证到一款同时符合“macOS 原生体验、本地优先、日阈值+周频率联合判断、独立显示窗口、逐期复盘、现有SketchyBar数据兼容”的完整替代品；这是一轮桌面调研的范围限制，不是不存在此类产品的证明。

| 应用 | 已有的相近能力 | 对本项目的意义 / 待核实差距 |
| --- | --- | --- |
| Untime | 每周预算、Grow最低投入与Reduce最高投入、计时会话、每日汇总与周统计。[官网](https://untime.app/) | 概念最接近，应作为直接竞品。App Store标注为为iPhone设计、未验证macOS体验，兼容栏列出Apple Silicon Mac；不能称为成熟原生Mac应用。[产品页](https://apps.apple.com/us/app/untime-time-hours-tracker/id6778267573)。本轮未确认有效天数+日阈值及周期复盘实例 |
| ATracker | 任务/标签日周目标、累计分组时间、统计图表、CSV导出、Web Dashboard。[官网](https://atracker.pro/) | 最接近“通用类别+时长目标+统计”的现成方案之一。官网的PC/Mac访问主要通过Web；不能据此等同原生本地应用。[平台说明](https://atracker.pro/Mobile/index.html)。联合频率规则及完整复盘历史待试用 |
| Timemator | 原生Mac计时；按规则自动触发计时；手动计时、会话编辑和备份。[官网](https://timemator.com/)、[自动计时手册](https://timemator.com/support/auto-tracking/) | 低成本记录和Mac交互值得借鉴；其按应用/文件规则自动化比当前SketchyBar更进一步。自定义有效天数及周期复盘是否能覆盖本需求尚未确认 |
| Timing | 自动记录Mac应用使用、再归类和查看投入。[官网](https://timingapp.com/) | 如果当前最大痛点是忘记开始计时，值得对照。自动应用使用时长不必然等于有效科研投入，仍需定义分类与排除规则；未验证本需求的联合目标和复盘任务 |
| Amazing Marvin | 目标、习惯、时间追踪、周期任务；显示/开始日期与截止日期可分别设置。[功能列表](https://amazingmarvin.com/features/all/)、[日期说明](https://help.amazingmarvin.com/amazing-marvin/the-different-dates-in-marvin) | 最接近“任务+目标+复盘流程”的综合工具。周期帮助明确说普通循环任务主要保留完成记录，若需要做与没做的历史应考虑习惯；不能直接等同这里每期独立实例与复盘快照。[循环任务说明](https://help.amazingmarvin.com/amazing-marvin/recurring-tasks) |
| Streaks | 支持每周若干天的习惯，例如每周健身3天；有统计和Mac版本。[官网](https://streaksapp.com/) | 适合用来比较阅读频率体验，但“每周3天，每天累计30分钟”能否由计时数据自动联合判断仍需实测；它也不直接替代工作时间预算与周复盘 |

建议先试用的顺序：

1. Untime：检验“以周预算为中心”的体验是否已经足够。
2. ATracker：检验通用类别、标签聚合和周目标是否满足个人使用。
3. Amazing Marvin：检验周期窗口、历史与复盘组织方式。
4. 若主要问题是漏记，再试 Timemator 或 Timing；若只是阅读习惯提醒，先看 Streaks。

每款试用统一用四个场景对比：科研20h但只有3个有效日；阅读1天90min与3天各30min；月末最后7天出现且月底截止；跨两个月后还能找到每期完成情况和复盘正文。另核实离线运行、账户要求、原始数据导出、数据驻留与迁移成本；这些未确认前不假定其符合本地优先要求。

如果只服务个人，可以优先接受现成工具组合；如果继续开发大众产品，值得验证的价值是“低成本记录→每周投入/频率反馈→定期复盘”的连贯体验和现有数据连续性。资产管理暂不纳入MVP，也不作为本轮差异化判断依据。
